# Provider Usage Policy

**Organization licensing policy: NOT_SPECIFIED**

Subscription-backed providers são destinados inicialmente ao desenvolvimento do
próprio titular autenticado. Não formam API pública, não são credential proxy,
não redistribuem OAuth, não autenticam terceiros, não compartilham assinatura
pessoal e ficam desabilitados em shared production. Termos vigentes dos vendors
continuam sendo autoridade superior; ambientes corporativos/CI devem preferir
API ou workload identity conforme contrato aplicável.
