# Benchmark estrutural Context v3 — 25 de agosto de 2026

## Resultado

Comando executado:

```bash
npm run benchmark:context-v3 -- .aicp/evaluations/context-v3.report.json
```

O benchmark determinístico usou 30 tarefas, 3 repetições e 343 chunks do
repositório (339 chunks). O relatório bruto fica em `.aicp/`, que é um diretório local de
artefatos e não é versionado.

| Métrica | Baseline | Candidate | Delta |
|---|---:|---:|---:|
| Execuções | 90 | 90 | — |
| Tokens médios selecionados | 4046,37 | 3947,53 | -2,44% |
| Precisão média de contexto | 0,133651 | 0,245065 | +0,111414 |
| Uso de vetor | 100% | 83,33% | -16,67 p.p. |

## Interpretação limitada

O resultado apoia manter o Context Compiler como capacidade mensurável: nesta
amostra, a seleção candidata melhorou a precisão e reduziu levemente o
envelope de tokens. Isso não é uma medição de qualidade de código, custo de
LLM ou aceitação humana.

O benchmark não populou Neo4j e usa uma projeção de grafo nula. Portanto ele
não prova ROI positivo ou negativo do grafo. Essa lacuna foi registrada em
[`ADR-009`](../adr/ADR-009-graph-default.md) e a decisão operacional permanece
Neo4j opcional, desligado por padrão.
