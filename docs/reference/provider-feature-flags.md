# Provider Feature Flags

| Flag | Default | Meaning |
|---|---|---|
| `AICP_AGENT_PROVIDER_LAYER_ENABLED` | `false` | ativa dispatcher |
| `AICP_AGENT_PROVIDER_DEFAULT` | `opencode-litellm` | default |
| `AICP_CODEX_PROVIDER_ENABLED` | `false` | habilita Codex local |
| `AICP_CLAUDE_CODE_PROVIDER_ENABLED` | `false` | habilita Claude local |
| `AICP_PROVIDER_FALLBACK_ENABLED` | `false` | permite fallback agentic |
| `AICP_SUBSCRIPTION_PROVIDERS_LOCAL_ONLY` | `true` | impede compartilhamento |
| `AICP_SUBSCRIPTION_PROVIDERS_CI_ENABLED` | `false` | CI opt-in separado |
| `AICP_LIVE_PROVIDER_TESTS` | `false` | permite inference de smoke |
