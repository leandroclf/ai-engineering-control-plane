# Provider Errors

`AUTH_REQUIRED`, `POLICY_DENIED`, `QUOTA_EXHAUSTED`, `PROVIDER_UNAVAILABLE`,
`PROVIDER_OUTPUT_LIMIT_EXCEEDED`, `PROVIDER_FALLBACK_CHECKPOINT_FAILED`,
`PROVIDER_INVALID_OUTPUT`, `PROVIDER_CANCELLED` e `PROVIDER_TIMEOUT` são
sanitizados. Nenhum erro inclui stdout/stderr irrestrito ou segredo.
