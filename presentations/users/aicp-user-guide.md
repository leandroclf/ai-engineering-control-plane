# AICP User Guide
From request to evidence-backed human review.
---
## What AICP does
Runs AI-assisted engineering work inside explicit budget, security and workflow boundaries.
---
## Start a run
Choose a project, task and recommended profile. Advanced settings never bypass Harness policy.
---
## Read the Overview
Start with release readiness, active work, blockers and observed evidence.
---
## Inspect a Run
Timeline, gates, findings, execution, budget, context provenance, attestations and audit are one drill-down away.
---
## Understand budget
Calls, tokens, estimated cost and physical fallback attempts are shown together.
---
## Understand gates
PASS links to its evidence; BLOCKED tells you what is missing; FAILED is never hidden behind a chart.
---
## Security findings
Findings remain visible with severity, tool and source artifact. Colour is never the only signal.
---
## Human review
The final decision remains with human review and protected CI.
---
## Demo Mode
Use deterministic fixtures to learn the product without provider keys, repository access or spend.
---
## Academy
Move from first run to architecture, security, context and extension modules.
---
## Where evidence lives
Open the source artifact or correlated trace; the UI presents provenance without exposing raw secrets.
